# FIFO vs LRU Cache Simulation

This project compares FIFO and LRU cache replacement algorithms using Python.
FIFO uses a queue, while LRU uses a doubly linked list.
The program reads memory addresses from a trace file and simulates cache accesses.
It calculates cache hits, misses, and hit ratios for different cache capacities.
Finally, it compares both algorithms to identify which performs better.
